개인정보처리방침

시행일: 2026년 11월 14일 · 운영자: 김형돈 · 문의: lynofind@gmail.com

LYNO Find는 휴대폰 안의 사진과 문서를 찾아 주는 앱입니다. 회원가입이 없고, 운영자는 서버를 두지 않으며, 이용자의 개인정보를 받지 않습니다. 사진과 문서를 읽고 검색하는 일은 모두 기기 안에서 이루어집니다.

1. 기기 안에서만 처리하는 정보

정보쓰는 이유
이용자가 허용한 사진사진 속 글자 읽기, 사진 내용 분석(비슷한 사진 찾기, 말로 사진 찾기)으로 검색. 촬영 날짜와 위치 같은 사진 정보도 색인에 함께 담습니다.
이용자가 고르거나 연결한 문서 (PDF, DOCX, XLSX, TXT, CSV)문서 제목과 내용 검색
음성 검색 때 말한 내용말을 검색어로 바꾸기. 기기 안의 음성 인식만 쓰며, 음성은 저장하지 않습니다.
앱 설정과 잠금 설정앱 동작. 기기의 보안 저장소에 둡니다.

검색을 위해 만든 색인은 암호화해서 기기에만 저장합니다. 사진 내용 분석에 쓰는 인공지능 모델은 앱 안에 들어 있어, 사진을 밖으로 보내지 않고 기기에서 돌아갑니다. 휴대폰을 충전 중일 때는 앱을 닫아 두어도 새 사진을 조금씩 이어서 색인할 수 있으며, 이것도 기기 안에서만 이루어집니다.

2. 외부로 보내는 정보

운영자는 사진, 문서, 사진 속 글자, 검색어, 음성을 받지 않습니다. 이용 통계나 분석 도구를 쓰지 않습니다. 앱의 인터넷 연결은 아래 광고와 새 버전 확인, 그리고 이용자가 직접 연결한 구글 드라이브(6항)에만 쓰입니다.

새 버전 확인: 앱을 열 때 새 버전이 있는지 한 번 확인합니다. 안드로이드에서는 Google Play 앱이 확인하고, 아이폰에서는 Apple App Store에 이 앱의 식별자(com.lynofind.app)만 보내 최신 버전 번호를 받습니다. 사진, 문서, 사진 속 글자, 검색어, 음성이나 이용자를 알아볼 수 있는 정보는 보내지 않습니다. 인터넷 통신의 특성상 Apple과 Google은 기기의 IP 주소를 받을 수 있습니다.

3. 광고

앱 화면 아래에 Google AdMob 배너 광고가 나옵니다. 광고를 보여 주고 부정 클릭을 막기 위해 Google이 다음 정보를 처리할 수 있습니다.

  • IP 주소와 이를 통한 대략적인 위치
  • 앱별 기기 식별자 같은 기기 정보
  • 광고 노출과 클릭 같은 광고 이용 기록
  • 광고 기능의 오류·진단 정보

LYNO Find는 맞춤 광고를 쓰지 않습니다. 광고 요청에는 사진, 문서, 사진 속 글자, 검색어, 음성을 넣지 않습니다. 동의가 필요한 지역에서는 광고를 처음 보여 주기 전에 Google의 동의 화면이 나오며, 동의 내용은 앱 설정의 “광고 개인정보 설정”에서 언제든 바꿀 수 있습니다. 광고를 불러오지 못해도 검색은 그대로 됩니다. LYNO Find Pro(출시 예정) 이용자에게는 광고를 보여 주지 않습니다.

Google의 정보 처리는 Google 개인정보처리방침과 Google 파트너 사이트·앱 이용 안내를 따릅니다.

4. 이용자가 직접 보내는 경우

검색 결과에서 사진이나 문서를 골라 ‘공유’하면, 이용자가 고른 앱으로 원본이 전달됩니다. 이후의 처리는 그 앱의 정책을 따릅니다. 앱이 스스로 사진이나 문서를 보내는 일은 없습니다.

사진사진 검색사진 검색만 되지 않습니다

문서는 이용자가 직접 고른 파일과 폴더만 읽습니다. 이용자가 구글 드라이브를 연결하면 6항처럼 드라이브의 파일을 읽기 전용으로 읽습니다.

6. 구글 드라이브 데이터 (Pro, 출시 예정)

LYNO Find Pro에서 제공할 예정인 기능입니다. 이용자가 직접 구글 계정을 연결하면 구글 드라이브의 파일도 휴대폰 안의 사진·문서와 함께 찾을 수 있습니다. 연결은 언제든 끊을 수 있고, 연결하지 않아도 앱의 다른 기능은 그대로 씁니다.

읽는 정보 (읽기 전용 권한 drive.readonly)

정보쓰는 이유
드라이브의 파일 목록검색할 파일 찾기
파일 이름, 종류, 크기, 수정 날짜, 폴더 같은 파일 정보검색 결과에 보여 주고, 바뀐 파일만 다시 색인하기
검색을 위해 내려받거나 이용자가 고른 파일의 내용파일 속 글자와 내용으로 검색하기, 이용자가 고른 파일을 휴대폰으로 내려받기, 공유 창으로 보내기

LYNO Find는 구글 드라이브의 파일을 만들거나, 고치거나, 지우거나, 공유 설정을 바꾸지 않습니다. 읽기 전용 권한만 요청합니다.

처리하고 저장하는 곳

  • 모든 처리는 이용자의 휴대폰 안에서만 이루어집니다. 구글 드라이브 데이터는 Google 서버에서 휴대폰으로 바로 내려오며, 운영자의 서버를 거치지 않습니다. 운영자는 서버를 두지 않습니다.
  • 휴대폰에 저장하는 것은 검색용 색인(파일 정보와 내용에서 만든 검색 자료)뿐이며, 암호화해서 기기 안에만 둡니다.
  • 검색이나 공유를 위해 내려받은 파일은 휴대폰의 임시 공간에 잠시 두었다가 작업이 끝나면 지웁니다. 원본은 구글 드라이브에 그대로 남습니다.
  • 구글 로그인 정보(인증 토큰)는 휴대폰의 보안 저장소에만 둡니다. 운영자는 이용자의 구글 비밀번호를 받지도, 보지도 않습니다.

공유: 검색 결과에서 파일을 골라 ‘공유’를 누르면, 파일을 휴대폰으로 내려받은 뒤 이용자가 고른 앱으로 전달합니다. 이후의 처리는 그 앱의 정책을 따릅니다. 앱이 스스로 구글 드라이브 데이터를 다른 사람이나 회사에 보내는 일은 없습니다.

하지 않는 일

  • 사람이 읽지 않습니다. 운영자를 포함해 누구도 이용자의 구글 드라이브 데이터를 볼 수 없으며, 서버가 없어 볼 수 있는 경로도 없습니다.
  • 광고에 쓰지 않습니다. 구글 드라이브 연결은 광고가 없는 Pro에서만 제공하며, 구글 드라이브 데이터를 광고 선택, 맞춤 광고, 리타게팅에 쓰지 않습니다.
  • 제3자에게 넘기지 않습니다. 팔거나, 데이터 중개업체·광고 회사·정보 판매자에게 전달하지 않으며, 대출이나 신용 판단에 쓰지 않습니다.
  • 인공지능 모델 학습에 쓰지 않습니다. 검색에 쓰는 인공지능 모델은 앱 안에 들어 있는 완성된 모델이며, 구글 드라이브 데이터로 이 모델이나 다른 어떤 모델도 학습·개선하지 않습니다.

연결 해제와 삭제

  • 앱 설정에서 “구글 드라이브 연결 해제”를 누르면 휴대폰에 있던 구글 드라이브 색인, 내려받은 임시 파일, 로그인 정보가 모두 지워지고 Google 접근 권한도 해제됩니다.
  • 앱을 지워도 이 데이터는 함께 지워집니다.
  • Google 계정의 서드파티 앱 권한 설정에서도 LYNO Find의 접근 권한을 언제든 없앨 수 있습니다. 이 경우 다음에 앱을 열 때 휴대폰의 구글 드라이브 색인을 지웁니다.

Google API 서비스 사용자 데이터 정책 준수: LYNO Find가 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 일은 제한적 사용(Limited Use) 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

7. 보관과 삭제

앱이 만든 색인과 설정은 기기에만 있습니다. 앱 설정의 “검색 색인 삭제”나 “모든 로컬 데이터 삭제”로 지울 수 있고, 앱을 삭제해도 함께 지워집니다. 검색어와 음성 인식 문장은 저장하지 않습니다. 앱은 원본 사진과 문서를 바꾸거나 지우지 않습니다. 구글 드라이브 데이터의 삭제는 6항을 따릅니다.

8. 아동

LYNO Find는 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 따로 수집하지 않습니다.
