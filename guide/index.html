LYNO Find 사용 설명서

LYNO Find는 휴대폰 안의 사진과 문서를 낱말로 찾아 주는 앱입니다. 사진 속 장면, 사진에 찍힌 글자, 문서 내용을 한 번에 찾고, 모든 분석과 검색은 휴대폰 안에서만 합니다. 앱의 "LYNO Find 100% 활용법"과 같은 순서로, 더 자세히 설명합니다.

1. 검색 정확도 올리는 방법

찾을 단어, 폴더 이름, 다중 검색, 음성 검색, 날짜·장소, 결과 안에서 더 찾기

1. 찾을 단어만 넣으세요2. 폴더 이름으로 찾으세요3. 마침표와 띄어쓰기 · 다중 검색4. 말로 편하게 물어보세요 · 음성 검색5. 찍은 곳·날짜를 함께 넣으세요6. 결과 안에서 한 번 더 찾으세요

2. 새로운 기능

묶음 폴더, 폴더 이름으로 검색, 스마트 폴더, 잠금 화면 위젯, 바로가기, 홈 화면 위젯

1. 묶음을 폴더 하나로 · 묶음 폴더2. 폴더 이름으로 찾으세요3. 스마트 폴더가 늘었어요4. 잠금 화면에서 바로 찾기 · 잠금 화면 위젯 (아이폰·아이패드)5. 1초 만에 찾기 · 바로가기6. 홈 화면에서 바로 찾기 · 위젯

3. 스마트 폴더 활용법

알아서 모아 주는 폴더, 켜고 끄는 법

1. 스마트 폴더란?2. 어떤 폴더가 있나요?3. 어떻게 쓰나요?4. 안심하세요
