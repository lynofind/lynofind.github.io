LYNO Find 사용 설명서

LYNO Find는 휴대폰 안의 사진과 문서를 낱말로 찾아 주는 앱입니다. 사진 속 장면, 사진에 찍힌 글자, 문서 내용을 한 번에 찾고, 모든 분석과 검색은 휴대폰 안에서만 합니다. 아래에서 궁금한 주제를 골라 보세요.

검색 잘하는 법

낱말 고르기, 여러 낱말 한 번에, 띄어쓰기로 좁히기, 날짜·장소, 결과 안에서 다시 찾기

문서 찾기

문서 폴더 연결, 문서를 정확히 찾는 요령, 지원하는 파일

스마트 폴더

알아서 모아 주는 폴더, 켜고 끄기, 묶음 폴더

사진 정리

중복·비슷한 사진, 지난 스크린샷, 잘못 찍힌 사진 지우기

위젯·말로 찾기

음성 검색, 시리, 앱 아이콘 바로가기, 홈·잠금 화면 위젯

잘 안 될 때

사진이 안 나옴, 분석이 느림, 문서가 안 나옴, 음성 검색

아래 탭

검색 · 사진(스마트 폴더, 지울 사진) · 문서 · 설정
